# Elastic models

The engines that compute Green's functions: a homogeneous half-space, and a layered
crust through the package's own wavenumber-domain tables, built from a
`VelocityModel`; and the correction for Earth's curvature and gravity that wraps them. See the guide page [Elastic models](../guide/elastic-models.md).
